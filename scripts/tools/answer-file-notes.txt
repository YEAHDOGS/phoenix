For Windows Updates, use powershell

Block all incoming connections in the network tab!

- Get all incoming windows updates

$u=(New-Object -ComObject Microsoft.Update.Session).CreateUpdateSearcher().Search("IsInstalled=0 and IsHidden=0").Updates; Write-Host "Total Updates Found: $($u.Count)" -ForegroundColor Cyan; ($u | Select-Object Title, Description, LastDeploymentChangeTime, @{Name="Type"; Expression={if($_.DriverClass) {"Hardware"} else {"Software"}}}, @{Name="Classification"; Expression={($_.Categories | Where-Object {$_.Type -eq 'UpdateClassification'} | Select-Object -ExpandProperty Name) -join ', '}}, @{Name="DriverClass"; Expression={$_.DriverClass}}, @{Name="DriverModel"; Expression={$_.DriverModel}}, @{Name="Manufacturer"; Expression={$_.DriverManufacturer}}, @{Name="Provider"; Expression={$_.DriverProvider}}, IsMandatory, @{Name="IsTrusted"; Expression={$_.IsTrusted}}, @{Name="NeedsReboot"; Expression={$_.InstallationBehavior.RebootBehavior -eq 1}}, @{Name="Size(MB)"; Expression={"{0:N2}" -f ($_.MaxDownloadSize / 1MB)}}, @{Name="DeploymentID"; Expression={$_.DeploymentAction}}, @{Name="UpdateID"; Expression={$_.Identity.UpdateID}}, @{Name="Identity.RevisionNumber"; Expression={$_.Identity.RevisionNumber}}, EulaUrl, UninstallationNotes | Sort-Object Title | Format-List); Write-Host "Total Updates Found: $($u.Count)" -ForegroundColor Cyan

- Download and install one of them

$ID="INSERT-UPDATE-ID-HERE"; $u=(New-Object -ComObject Microsoft.Update.Session).CreateUpdateSearcher().Search("IsInstalled=0").Updates | Where-Object {$_.Identity.UpdateID -eq $ID}; $c=New-Object -ComObject Microsoft.Update.UpdateColl; $c.Add($u) | Out-Null; Write-Host "Downloading: $($u.Title)" -ForegroundColor Yellow; $d=(New-Object -ComObject Microsoft.Update.Session).CreateUpdateDownloader(); $d.Updates=$c; $d.Download() | Out-Null; Write-Host "Installing..." -ForegroundColor Green; $i=(New-Object -ComObject Microsoft.Update.Session).CreateUpdateInstaller(); $i.Updates=$c; $r=$i.Install(); Write-Host "Result Code: $($r.ResultCode) (2=Success, 3=Reboot Required)" -ForegroundColor Cyan

To display all system drivers currently installed and running, use these commands

- Display all running system drivers in a nice window

Get-CimInstance Win32_SystemDriver |
Where-Object { $_.State -eq "Running" } |
ForEach-Object {
    $sig = Get-AuthenticodeSignature $_.PathName
    [PSCustomObject]@{
        Name        = $_.Name
        DisplayName = $_.DisplayName
        StartMode   = $_.StartMode
        State       = $_.State
        PathName    = $_.PathName
        Publisher   = if ($sig.SignerCertificate) { $sig.SignerCertificate.Subject } else { "Unsigned/Unknown" }
        Status      = $sig.Status
    }
} | Out-GridView

- Malicious volumes often use "Filters" to hide their true purpose from Windows Defender (Control 117). Run this command in PowerShell (Admin) to see if there is a "Shadow Service" sitting on top of your storage:

Get-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Class\{71a27cdd-812a-11d0-bec7-08002be2092f}" | Select-Object UpperFilters, LowerFilters

- Standard Result: LowerFilters should be empty or fvevol (BitLocker). UpperFilters should be empty or volsnap. Red Flag: If you see any random filenames (e.g., wdfilter, btmod, or strings of numbers), that is the driver that is "faking" the 8 volumes.

- Potentially bad output (iorate and rdyboost may be malicious):
LowerFilters               UpperFilters
------------               ------------
{fvevol, iorate, rdyboost} {volsnap}

.cmd - add windows update urls to hosts file, prevent any connection to them entirely.

@echo off
:: Block Windows Update / Driver domains in hosts file
:: Safe to run multiple times (checks for existing entries)
:: Designed for unattend.xml RunSynchronous or manual run as admin

:: Require Administrator
net session >nul 2>&1
if %errorLevel% neq 0 (
    echo ERROR: This script must be run as Administrator.
    echo Right-click Run as administrator
    pause
    exit /b 1
)

echo.
echo Adding blocks to %SystemRoot%\System32\drivers\etc\hosts
echo (prevents auto-driver downloads from Microsoft during/after install)

set "HOSTS=%SystemRoot%\System32\drivers\etc\hosts"

:: Domains to block (focused on driver/update servers)
set "DOMAINS=download.windowsupdate.com windowsupdate.microsoft.com *.windowsupdate.microsoft.com update.microsoft.com *.update.microsoft.com download.microsoft.com *.download.windowsupdate.com wustat.windows.com ctldl.windowsupdate.com slscr.update.microsoft.com ntservicepack.microsoft.com"

:: Append missing entries
(for %%d in (%DOMAINS%) do (
    findstr /C:"0.0.0.0 %%d" "%HOSTS%" >nul
    if errorlevel 1 echo 0.0.0.0 %%d
)) >> "%HOSTS%"

echo.
echo Done. Current blocked entries in hosts file:
findstr /C:"0.0.0.0" "%HOSTS%" | findstr /C:"windowsupdate" /C:"update.microsoft" /C:"download" /C:"wustat" /C:"ctldl"

echo.
echo For changes to take effect immediately, run these commands:
echo   ipconfig /flushdns
echo   net stop wuauserv ^&amp; net stop bits ^&amp; net start wuauserv ^&amp; net start bits
echo   (or restart "Windows Update" service in services.msc)
echo.
echo Recommended: Reboot the system after this.
echo.
echo To allow a specific driver later (selective update):
echo 1. Open %HOSTS% in Notepad as admin
echo 2. Comment out (#) or remove the unwanted lines
echo 3. Save, then run ipconfig /flushdns + restart services
echo 4. Go to Settings ^&gt; Windows Update ^&gt; Check for updates
echo.
